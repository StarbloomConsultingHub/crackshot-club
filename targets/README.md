# Targets (printable PDFs)

Letter-size printable targets and score cards for **Pull the Sleeve** and **The Short Stack**.

**Score cards:** the first official cards are in [`2026-11-pull-the-sleeve/`](2026-11-pull-the-sleeve/). Target of the Month #1 is still in the works.

- One folder per release: `targets/<YYYY-MM>-<short-name>/` with the PDF, a preview image, and a README.
- Target of the Month drops on the 1st of each month with a matching score card.
