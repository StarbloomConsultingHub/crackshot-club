# Contributing a design or target

Thanks for building something for the club. 22 Crack Shot shares designs so anyone can print a trap or a target and play.

## What we accept

- **Traps and throwers** for crackers or mini clays
- **Cracker rails, target holders, stands, and score boards**
- **Printable targets and score cards** (Letter-size PDF)

## What we never accept

- Firearm parts of any kind, or anything that attaches to or modifies a firearm
- Barrel, boring, or smoothbore-conversion jigs or instructions
- Anything ammunition-related (reloading tools, shell parts)
- Files you didn't make, or files whose license doesn't allow sharing (link to the original instead)

Submissions that break these rules are closed without discussion.

## How to submit

1. **Fork** this repository and create a branch, for example `design/cracker-rail-v1`.
2. Add a folder:
   - 3D designs: `designs/<short-name>/` (for example `designs/cracker-rail/`)
   - Targets: `targets/<YYYY-MM>-<short-name>/` (for example `targets/2026-12-duck-row/`)
3. Put these in the folder:
   - Source files (`.step`, `.f3d`, `.scad`, `.3mf`, or `.svg` / `.ai` for targets) where you have them
   - Print-ready files (`.stl` / `.3mf`, or `.pdf` for targets)
   - At least one photo or render (`.jpg` / `.png`, under 2 MB)
   - A short `README.md` using the template below
4. Open a **pull request**. By submitting, you agree your files are your own original work and are released under **CC BY-NC-SA 4.0** (see `LICENSE-DESIGNS.txt`).
5. A maintainer reviews it, may ask for changes, and merges it when it's ready.

No GitHub account? Post it on the club message board in **Traps & 3D Designs** and a maintainer can add it with credit.

## README template for a design

```markdown
# <Design name>

- Designer: <name or handle>
- Version: v1
- What it does: <one or two sentences>
- Print settings: <material, layer height, infill, supports>
- Hardware: <screws, springs, etc. with sizes>
- Assembly notes: <short>
- License: CC BY-NC-SA 4.0
```

## Style for targets

- Letter size (8.5 x 11 in), printable on a home printer
- Club palette if you like: Carnival Red `#C41E3A`, Cream `#F3E6C8`, Navy `#1C2E4A`, Brass `#C4A354`
- No snack-brand logos or other trademarks
