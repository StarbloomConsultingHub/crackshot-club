# Designs (3D-printable)

Traps, cracker rails, target holders, stands, and score boards for 22 Crack Shot games.

**Status:** placeholder. The first club designs (a mini cracker trap and a gallery-row cracker rail) are being prototyped.

- One folder per design: `designs/<short-name>/` with source files, print files, a photo, and a README. See [CONTRIBUTING.md](../CONTRIBUTING.md).
- License: CC BY-NC-SA 4.0 ([LICENSE-DESIGNS.txt](../LICENSE-DESIGNS.txt)) unless a design's README says otherwise.
- **Never:** firearm parts, barrel or conversion jigs, or anything ammunition-related.
